# Stuckers

Real X authentication through Privy, persistent social data in Supabase, and automatic Vercel deployment.

## Deploy

1. Upload every file and folder in this project to the root of the GitHub repository.
2. Keep the five environment variables already added in Vercel.
3. Redeploy the latest commit.

Never commit `.env.local`, Privy App Secret, Supabase Secret Key, or the database password.
